# Changelog

## 1.0.0

- Richer Windows tray menu: Open, Restart, Check for Updates, Theme submenu, and Exit, each with its own icon.
- Per-item icons with light/dark variants that follow the system appearance.
- Theme submenu switches the application between light, dark, and follow system, mirroring the in-app appearance control.
- Settings page chooses the tray menu language (Chinese, English, or follow the application).
- Self-maintaining shell patch: applies once per DSH version, re-applies after an update, and restores the original on uninstall.
